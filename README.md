# Komentář k zákonu č. 65/2017 Sb., o ochraně zdraví před škodlivými účinky návykových látek

Otevřený komentář k zákonu o ochraně zdraví před škodlivými účinky návykových látek — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; omezení dostupnosti tabákových výrobků, elektronických cigaret a alkoholu, zákaz kouření, psychomodulační látky, vyšetření přítomnosti alkoholu, protidrogová politika, působnost správních orgánů a přestupky.

Konsolidované znění: dokument e-Sbírky `SB-2017-00065_2025-07-01`.
